EasyTransfert

Envoyer des fichiers entre cet ordinateur et votre téléphone, sans câble et sans rien installer sur le téléphone.

Démarrer

  1. Double-cliquez sur Lancer EasyTransfert

    C'est le seul fichier à utiliser. Une fenêtre noire s'ouvre : c'est normal, c'est le programme qui tourne. Ne la fermez pas tant que vous transférez des fichiers.

  2. Si Windows affiche « Windows a protégé votre ordinateur »

    Cet écran bleu apparaît parfois au tout premier lancement, simplement parce que le programme vient d'être copié depuis un autre ordinateur. Cliquez sur Informations complémentaires, puis sur Exécuter quand même.

    Si cet écran n'apparaît pas, passez directement à l'étape suivante.

  3. La toute première fois, Windows demande une autorisation

    Une fenêtre bleue apparaît et demande si vous autorisez le programme à modifier l'appareil. Cliquez sur Oui. Sans cela, le téléphone ne pourra pas se connecter.

    Cette question n'est posée qu'une seule fois, au premier démarrage.

  4. Votre navigateur s'ouvre tout seul

    Une page s'affiche avec un grand QR code (le carré noir et blanc). C'est cette page qui sert à envoyer et recevoir les fichiers depuis l'ordinateur.

  5. Sur le téléphone, scannez le QR code

    Ouvrez simplement l'application Appareil photo du téléphone et visez le QR code affiché à l'écran de l'ordinateur. Un lien apparaît : touchez-le. La même page s'ouvre sur le téléphone.

    Important : le téléphone doit être connecté au même Wi-Fi que l'ordinateur. S'il est en données mobiles (4G / 5G), cela ne fonctionnera pas.

    À faire une seule fois : une fois la page ouverte sur le téléphone, ajoutez-la à l'écran d'accueil (menu du navigateur → « Ajouter à l'écran d'accueil »).

    Les fois suivantes, il suffira de toucher cette icône : plus besoin de scanner le QR code, même après avoir éteint l'ordinateur.

  6. Envoyez vos fichiers

    Sur l'un ou l'autre appareil, appuyez sur Envoyer des fichiers et choisissez ce que vous voulez transférer. Depuis l'ordinateur, vous pouvez aussi faire glisser des fichiers directement dans le cadre en pointillés.

    Le fichier apparaît immédiatement sur l'autre appareil, sans rien recharger. Appuyez sur Télécharger pour le récupérer.

Bon à savoir

Où sont rangés les fichiers ?
Dans le dossier partage, à côté de ce mode d'emploi. Ils y restent tant que vous ne les supprimez pas.
Comment tout effacer d'un coup ?
Le bouton Tout supprimer, à droite de « Fichiers partagés ». Une confirmation est demandée. C'est définitif.
Faut-il rescanner le QR code à chaque fois ?
Non. Le lien reste valable d'une fois sur l'autre : si vous avez ajouté la page à l'écran d'accueil du téléphone, touchez simplement l'icône. Le QR code ne sert que pour un nouvel appareil.
Comment arrêter le programme ?
Fermez la fenêtre noire. Les fichiers déjà transférés restent sur l'ordinateur.
Est-ce que mes fichiers passent par Internet ?
Non. Tout reste à l'intérieur de votre réseau Wi-Fi, directement entre les deux appareils. Rien n'est envoyé sur Internet, rien n'est stocké ailleurs.

Si le téléphone n'arrive pas à ouvrir la page

Vérifiez dans cet ordre :

1. Le téléphone est-il sur le même Wi-Fi que l'ordinateur ?
C'est la cause la plus fréquente. Désactivez les données mobiles pour en être sûr.
2. Essayez une autre adresse
Sur l'écran de l'ordinateur, sous le QR code, il y a un menu déroulant « Adresse du PC ». Choisissez-en une autre : le QR code change aussitôt, il suffit de le rescanner.
3. Votre réseau Wi-Fi est-il déclaré « privé » ?
Dans Windows : Paramètres → Réseau et Internet → Wi-Fi → votre réseau, puis cochez Réseau privé. Sur un réseau déclaré « public », Windows bloque volontairement la connexion.

À n'utiliser que sur votre réseau à la maison. Sur un Wi-Fi public (gare, hôtel, café), n'utilisez pas ce programme : la connexion n'est pas chiffrée.

EasyTransfert fonctionne entièrement hors ligne. Il embarque sa propre copie de Node.js (dossier node, licence MIT) : rien d'autre n'a besoin d'être installé sur l'ordinateur.
